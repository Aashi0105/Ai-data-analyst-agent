# Evaluation & Demo Datasets

This directory contains synthetic datasets created strictly for evaluation benchmarks, automated testing, and demonstration.

- `ecommerce_sales.csv`: A synthetic benchmark dataset of 100 simulated e-commerce transactions across 2023.
  - Contains numerical metrics (quantity, unit price, revenue, profit), categorical dimensions (region, category, product, customer), temporal data (order dates), and realistic missing values.
  - **Notice**: This dataset does not represent real customer or production data. It is programmatically generated for reproducible testing and evaluation.
